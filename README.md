# موقع تراكسو (Traxo) — Landing Page

مشروع لاندنق بيج جاهز يشتغل بـ Vite، بحيث تقدر تفتحه بـ VS Code وتشغله بأمر `npm run dev` زي أي مشروع Node عادي.

## المتطلبات
- Node.js مثبت عندك (يفضل نسخة 18 أو أحدث). تقدر تتأكد بكتابة `node -v` بالـ Terminal.

## طريقة التشغيل (أول مرة بس)
1. فك ضغط المجلد وافتحه بـ VS Code
2. افتح Terminal داخل VS Code: **Terminal > New Terminal**
3. ثبّت المكتبات:
   ```
   npm install
   ```

## التشغيل اليومي (بعد التثبيت)
```
npm run dev
```
بيطلع لك رابط زي `http://localhost:5173/` — افتحه بالمتصفح (أو Ctrl+Click عليه من الـ Terminal).
أي تعديل تسويه بالكود ينحدّث بالمتصفح تلقائيًا (Hot Reload) بدون ما تسوي Refresh يدوي.

## بناء نسخة نهائية للنشر (Production Build)
```
npm run build
```
بينشئ مجلد `dist/` فيه نسخة مضغوطة وجاهزة للرفع على أي استضافة (Vercel, Netlify, أي سيرفر عادي...).

لمعاينة نسخة الـ build محليًا قبل الرفع:
```
npm run preview
```

## هيكل الملفات
```
traxo-project/
├── package.json          إعداد المشروع وأوامر npm
├── vite.config.js        إعداد Vite (صفحات متعددة: index / privacy / terms)
├── index.html             الصفحة الرئيسية
├── privacy.html           سياسة الخصوصية
├── terms.html             الشروط والأحكام
├── css/
│   └── style.css          كل التنسيقات (الألوان كمتغيرات CSS بالأعلى)
├── js/
│   └── script.js          تفاعل الأسئلة الشائعة + زر اللغة
└── assets/
    ├── logo.svg                 أيقونة الشعار (رمز السيارة)
    ├── map-pattern.svg          خلفية الخريطة
    ├── hero-illustration.svg    رسمة القسم الرئيسي
    ├── feature-delivery.svg     رسمة "توصيل سريع لأغراضك"
    └── feature-tracking.svg     رسمة "رحلة آمنة لوجهتك"
```

## التعديل على المحتوى
- **النصوص**: عدّلها مباشرة داخل `index.html` / `privacy.html` / `terms.html`
- **الألوان**: كلها متغيرات CSS بأعلى `css/style.css` تحت `:root` — غيّر `--orange` وغيرها وبتنعكس على كل الموقع تلقائيًا
- **الشعار / الصور**: استبدل ملفات SVG داخل `assets/` بصورك الخاصة (بنفس الاسم)، أو غيّر مسار `src` بالـ HTML لو حاب تستخدم PNG/JPG

## ملاحظة
زرّي "الشروط والأحكام" و"سياسة الخصوصية" بأسفل كل صفحة شغالين فعليًا ويوديانك لصفحتين مستقلتين فيهما المحتوى اللي جهزته.
